# Circle Video Finder (Chrome Extension - Manifest V3)

> هذه الإضافة تساعدك في **اكتشاف روابط الفيديو الظاهرة والمتاحة** داخل صفحات Circle.so (مثل MP4 أو M3U8) من أجل الاستخدام المصرّح به فقط.

## الملفات
- `manifest.json`
- `content_script.js`
- `popup.html`
- `popup.css`
- `popup.js`

## كيف تعمل
1. تضغط زر **Scan for Videos** من نافذة الإضافة.
2. يتم فحص الصفحة الحالية بحثًا عن:
   - وسوم `<video>` و `<source>`
   - روابط تحتوي على امتدادات فيديو (MP4/M3U8/WebM/MOV)
3. تظهر النتائج مع أزرار:
   - **Download** للروابط المباشرة (أو فتح الرابط إذا تعذّر التحميل)
   - **Copy URL** لنسخ الرابط

## ملاحظة بخصوص HLS (m3u8)
- ملفات `m3u8` غالبًا تكون Playlist لبث HLS وليست ملف فيديو واحدًا.
- أفضل طريقة برمجية (عند وجود صلاحية قانونية):
  - نسخ رابط `m3u8` ثم استخدام أداة خارجية مثل:
    ```bash
    ffmpeg -i "<M3U8_URL>" -c copy output.mp4
    ```
- إذا كان البث محميًا بـ DRM أو يتطلب توثيقًا خاصًا، فلن تنجح طرق التحميل المباشر.

## التثبيت اليدوي (Developer Mode)
1. افتح Chrome ثم اذهب إلى: `chrome://extensions`
2. فعّل **Developer mode**
3. اضغط **Load unpacked**
4. اختر المجلد الذي يحتوي ملفات الإضافة
5. افتح صفحة ضمن نطاق `*.circle.so` ثم شغّل الإضافة

## صلاحيات الإضافة
- `activeTab`: للوصول للتبويب الحالي وفحصه.
- `storage`: حفظ نتائج آخر فحص محليًا.
- `declarativeNetRequest`: مضمنة حسب طلبك التقني.
- `host_permissions` على `*://*.circle.so/*`.

## تنبيه
استخدم الإضافة فقط للمحتوى الذي تملك حق الوصول والتنزيل له، ووفق شروط الخدمة والقوانين المحلية.
